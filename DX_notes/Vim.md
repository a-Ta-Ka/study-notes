# Vim

##  介绍

Vim常用于**SSH和无桌面环境中**的配置、代码编辑。

Vim有三种模式，他们的名字和大致作用分别是：
- 命令行模式 ——保存、退出、搜索等
- 正常模式——浏览、宏观上处理文本 
- 编辑模式——添加、修改文本

打开终端，输入`vim xxxx`，即可以正常模式打开或新建文件。

> 需要注意的是，vim对于xxxx不是很严格，无论是相对路径还是绝对路径都能打开对应文件，相对应的，平时要多注意一下路径拼写是否有误，不然会直接新建空文件的。

## 正常模式

```cpp
Esc         //从编辑模式进入正常模式
i/I         //从光标左边进入编辑模式 / 从整行最左边进入
a/A         //从光标右侧进入编辑模式 / 从整行最右边进入
o/O         //新增下一行进入编辑模式 / 新增上一行进入

G/gg        //光标移动到最后一行 / 移动到最顶行
5j          //往下移动 5 行
5k          //往上移动 5 行
w           //移动到下个单词首部
e           //移动到下个单词尾部
b           //移动到上个单词首部

yy          //复制当前行， y 就是复制的意思
yw          //复制单个单词
p           //粘贴到所处行
dd          //删除当前行， d 就是删除的意思
dw          //删除此字符
cw          //删除此字符并进入编辑模式
ci{         //删除括号内所有并进入编辑模式

.           //重复上一次的操作
u           //撤回上一次的操作
ctrl + r    //重做上一次的撤回

ctrl + v    //可视化块，同于鼠标的框选
shift + v   //可视化行

hjkl   //对应着上下左右移动光标
：  //进入命令行模式
```

## 命令行模式

```cpp
：      //进入命令行模式，其实很多时候：直接复合到指令里面去了

ZZ      //在正常模式下直接保存退出
:q      //仅退出
:q!     //不保存退出
:wq     //保存退出

:/xx | n       //搜索xx后定位 / 跳下一个匹配  
:%s/旧/新/g    //直接全局替换，完成后进入正常模式
```

## 配置

如果需要改变vim的一些设置，比如说想要看见行号那么就要到 `user vimrc `里面加东西配置。
```cpp
set number            //显示行号
set relativenumber    //显示相对行号，利于光标移动
set hlsearch          //高亮搜索结果
```
